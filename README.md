# Calculator

A simple calculator in Python. It can add, subtract, multiply, and divide any numbers.

## Features

- Four operations: `+`, `-`, `*`, `/`
- Protection against division by zero
- Counts how many operations you did
- Works with words too: `add`, `subtract`, `multiply`, `divide`
- Exit with `stop`, `exit`, `quit`, or `end`

## How to run

1. Install Python
2. Run `calculator.py`
3. Enter two numbers
4. Enter an operation
